# Exact candidate repair

Read the exact failed leaf logs and receipts in the recorded check state. Diagnose
product, invalid composed fixture, infrastructure and missing credentials separately.
Only candidate fixes are authorized. Preserve main, published integration and all
feature PRs. Generic feature bugs need an upstream-facing finding in the report;
do not silently label them integration problems. Preserve the published migration
prefix and all required proof. If target test code or CI suite registration is
wrong, repair its supported setup and add/extend meaningful regression coverage.
Do not change the frozen control recipe, hide skips, weaken sandboxing or install
local dependencies. Do not rerun a whole workflow merely to erase a failure.
