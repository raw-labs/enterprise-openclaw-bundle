# Report a security issue privately

Use **Security → Report a vulnerability** in GitHub or your existing private
RAW Labs support channel. If neither is available, ask for a private reporting
route without including vulnerability details.

Include the bundle version, affected component and source identity from
`metadata/release.json`, platform, impact and minimal reproduction steps.
Send sanitized evidence first. Keep credentials, customer identifiers,
kubeconfigs and raw logs out of public reports.
